# BeatChart Arcade

本地运行、完全离线的音游（Windows 桌面 + Android）：导入你自己的音乐，自动分析 BPM 与节拍，自动生成 **E / H / EX** 三档谱面，选难度即可开玩。每一档都支持无限次「重抽（Reroll）」——不满意就重新掷骰子，直到出现你喜欢的手感。

## 下载即玩

- **Windows 便携版**：[BeatChartArcade-Portable-1.8.1.exe](https://github.com/shizuku-zxy/BeatChart-Arcade/releases/download/v1.8.1/BeatChartArcade-Portable-1.8.1.exe)
  - 双击即运行，无需安装任何运行时、无需联网；数据存在 exe 同目录 `BeatChartData/`，整个文件夹拷 U 盘即随身携带。
- **Android 版（APK）**：[BeatChartArcade-Android-1.8.1.apk](https://github.com/shizuku-zxy/BeatChart-Arcade/releases/download/v1.8.1/BeatChartArcade-Android-1.8.1.apk)
  - 传到手机安装（需允许“未知来源/安装未知应用”），完全离线；
  - **锁定横屏**，默认透视式玩法（音符从远端飞向判定线，触摸点轨道列击打；设置可切下落式）；
  - v1.5.0 起自动补偿音频输出延迟，若仍觉手感偏移请用设置 → 🎯 触屏与延迟校准；
  - 数据存应用内部 IndexedDB；Android WebView 原生支持 MP3/WAV/OGG/FLAC。

> 预编译产物统一发布在 [GitHub Releases](https://github.com/shizuku-zxy/BeatChart-Arcade/releases) 页面；源码仓库不包含 `node_modules/`、`dist/`、`release/` 等构建产物。

两种设备共用同一套分析/生成/判定引擎，只是渲染与输入层不同。

## 导入方式

- **音频**：拖拽（支持批量）或「导入音频文件」→ 自动分析 + 生成三档；
- **谱面包**（.osz/.mcz，含音频）：拖入窗口或曲库页「导入谱面包」→ 解包新建歌曲；
- **单谱面**（.osu/.mc/.sm/.ssc）：选曲页「导入谱面」挂到该歌（需音频已在库）；
- **手录**：选曲页「新建手录谱」→ 选起点（空白谱 / E/H/EX / 自定谱底稿）→ 放音乐点击录入；可慢放三档、可拖时间轴回退（回退区标灰、重录同刻自动替换）、录制/编辑双模式随时切换；
- **Android**：同上（系统文件选择器）。

导入后自动走完「分析 → 三档谱面生成」并直接跳到选曲页，选难度即可开玩。

- **v1.8.0**（2026-10-28）谱面质量算法大升级：人声层 + 结构层 + 落点吸附 + 键型连贯（参照 DDC/ISMIR 2017 源码拆解，规则路线增量演进）
  - **分析器 v4——人声层**：新增人声基频区（150-820Hz）谱通量与 `vocalOnsets`（进唱/换句事件）。人声/军鼓频带重叠是经典难题（首次实现被人声冒充的假军鼓全数误杀），最终判别特征为**瞬态带宽比**（人声能量集中基频区 ≈0.75 vs 军鼓宽带均匀 ≈0.36，阈值 0.55 分界，不受持续和声干扰）：合成音频 32 个人声起音精确检出 32-34 个，同时军鼓检测回归真值（22 vs 期望 ~23，人声冒充者被正确剔除）；
  - **分析器 v4——结构层**：`segments2` 小节对齐变化点分段（特征 = 能量+人声活跃+onset 密度，边界 = 相邻小节特征距离 > mean+1σ 自适应阈值，<2 小节短段并入邻段）+ 段落标签（intro/verse/chorus/inst/break/outro）——合成音频完美命中 chorus@副歌 + outro@尾奏；
  - **头/尾静音检测**同步升级进 v4 输出（audioStart/audioEnd）；
  - **生成器——落点吸附**（DDC OnsetNet 的规则近似）：主位槽（拍点/反拍八分）向 ±40ms 内最强 onset 微调（源 = 全带+人声+和声 onset），note 落点与实际音乐事件对齐；十六分加花位保持纯网格（不被拉偏）；E 档不吸附（新手规整网格优先）；同 beat 吸附重叠去重保网格可读性；
  - **生成器——事件分层驱动键型**（参照 Mapperatorinator 事件分层）：人声主导段 flow/mirror 权重 ×(1+0.6×活跃度)（跟人声流动）、和声 onset 密集段 flow 再提权；`tonalOnsets`（v3 就检测了但从未接入生成——"白算"修复）一并接入；
  - **生成器——键型序列连贯**（DDC n-gram 思想的规则版）：相邻小节键型相容性权重（同型延续 ×1.2 / 相关 ×1.0 / 跳变 ×0.8），消除 measure 间生硬切换；
  - **选曲页「升级分析」**：更多面板新增入口（仅旧版本分析的歌显示）——重跑 v4 分析并重生成三档（原 seed 保留、旧谱入 history 可回退）；旧歌库不升级则自动回退 v3 行为；
  - 测试 222 项全绿（新增 v4 断言：人声检出数量/对齐/区间集中、结构段标签、吸附生效直接证据（H 谱 11 个 note 贴人声 onset vs E 谱 0 个）、v3 旧缓存回退）；本地 + 打包版双冒烟 0 退出。

## 核心闭环

```
导入 mp3/wav/ogg/flac（拖拽或点击）
  → 自动分析（Worker 中执行，不卡界面）：BPM、节拍偏移、beat 网格、onset 强度、RMS 动态、段落能量
  → 自动生成 E（低密度）/ H（中密度）/ EX（高密度）三档独立谱面
  → 选难度 → 开始游玩（2 秒倒计时）
  → 判定 / 连击 / 分数 / 准确率 / 评级 / 结算
  → 每档可无限「重抽」（显示 seed，可回退上一版），重抽后立即可玩
```

## 操作

| 操作 | 说明 |
| --- | --- |
| 4 轨键位 | `D` `F` `J` `K`（设置中可逐键自定义） |
| 触屏 | 点按轨道落点判定；透视式与下落式共用同一判定线；右上角暂停按钮 |
| 长按（hold） | 头部正常击打，按住到尾部；提前松手有 0.35s 宽容，断开后可重新按住恢复 |
| 暂停 / 继续 | `Esc`（桌面）/ 右上角按钮（触屏）；音频与时钟同步冻结，恢复无漂移 |
| 重试 / 返回 | 暂停菜单与结算页均提供 |

**判定窗口**：PERFECT ±50ms / GREAT ±100ms / GOOD ±150ms / MISS。
**分数**：900,000 × 准确率权重 + 100,000 × 最大连击达成；评级 SSS ≥ 99.5%、SS ≥ 98%、S ≥ 95%、A ≥ 90%、B ≥ 80%、C ≥ 70%。

## 重抽（Reroll）机制

- 每档难度卡片上有「🎲 重抽」按钮：以**新随机 seed** 重新生成该档 note 布局（含键型重新抽选），复用已缓存的分析结果（瞬时完成，立即开玩）。
- 「↩ 回退」可撤销到上一版（最多保留 12 版历史）。
- seed 直接显示在卡片上，也可手动输入任意 seed 复现某个布局——**相同 seed 永远生成完全相同的谱面**。
- 所有谱面改动自动持久化，重启后仍在。

## 键型体系

谱面按小节（barGrid 对齐）从键型库抽选，参考 osu!mania / BMS 社区术语：

| 键型 | 术语 | 说明 |
| --- | --- | --- |
| 流动 | Stream/切 | 单键自然流，左右手交替倾向，邻轨衔接 |
| 楼梯 | Stair | 折返阶梯 0-1-2-3-2-1-0…，上下行随机，snare 反拍段权重提升 |
| 交互 | Trill | 落点左右交替（1-2-1-2 相邻对为主，0-2/1-3/0-3 跨手为辅），hihat 密集段权重提升 |
| 纵连 | Jack/叠 | 同轨连续 2~4 键，仅在相邻间隔足够的连续段上生成 |
| 多压 | Chord/双押 | 对称双押（0+3 / 1+2），**锚定 kick 落点**（优先小节头），无 kick 的小节不出双押 |
| 散打 | Mirror | 4 键基础序列 + 左右镜像，周期重复（接缝不重轨） |
| 急楼梯 | Roll | 十六分密集区快速折返（仅 EX 高能量 + hihat 密集小节） |

**难度分层**：E 只有流动/楼梯/散打；H 加交互与低频多压/2 连纵连；EX 全键型开放（含 4 连纵连与急楼梯）。

**hold 单侧约束**：长键存续期间，其余短键只出现在**对侧手区**（4 键：hold 在 D/F 时短键只能在 J/K）——消除“两侧夹击”不可打排列；v1.7.1 起解除“全局仅一个 hold”限制，跨轨长键可并存（同轨约束与 hand-zone 清理仍然生效）。选曲页可查看每张谱的键型构成。

## 音乐分析维度（v4 分析引擎）

| 维度 | 方法 | 谱面用途 |
| --- | --- | --- |
| 底鼓 kick | 30-130Hz 低频瞬态（频带 flux + 自适应阈值） | 多压锚点、密度骨架 |
| 军鼓 snare | 180-2000Hz 中宽带瞬态 | 反拍重音、楼梯权重 |
| 踩镲 hihat | 5-11kHz 高频瞬态 | 细分素材：交互/急楼梯权重 |
| 调性 key | 4096 点高分辨率 chroma（谱峰抛物线插值）+ K-S 24 调相关 | 选曲页展示 |
| 拍号/小节线 | kick 能量四相位评分 + 自相关判别 3/4 | 多压落小节头、散打/楼梯对齐小节 |
| tatum | 打击乐事件合并网格覆盖率 | 三档细分密度封顶（不违背歌曲律动） |
| 持续和声 | chroma 稳定窗口 | hold 落点偏好 |

所有计算仍在同一 Worker 内（v4 新增人声层、结构分段与独立高分辨率 chroma 通道），零外部依赖、完全离线。旧分析缓存自动回退 v3/v2 行为；v1.8.1 起应用启动后自动后台升级旧版分析（seed 保留、旧谱入 history 可回退），选曲页也保留「升级分析」手动入口。

## 导出

在选曲页每档卡片上可导出：

- **chart.json**：metadata + 分析摘要（BPM/offset/段落/RMS）+ 完整 notes。
- **MIDI 节奏轨**：`.mid`（轨道映射音高 60+lane，含速度事件，可导入 DAW）。
- 页面顶部可导出整曲**分析 CSV**（onset / beat / 段落能量明细）。

## 设置（持久化）

- 固定 4 轨（`D` `F` `J` `K`），逐键自定义键位
- 画面模式（自动 / 下落式 / 透视式；自动 = 统一透视式）
- 下落速度（1–15 级；判定窗口固定毫秒，与流速无关）、音乐音量、打击音效开关
- **触屏与延迟校准页**：音频管线信息、触摸几何检测、触屏节拍校准
- **延迟校准器**：跟随 12 拍节拍点击空格，自动测量并补偿输入偏差
- 谱面偏移微调（±200ms）

**时钟方案**：游玩主时钟严格使用 `AudioContext.currentTime`（硬件音频时钟），渲染循环仅采样该值而不做任何累加，因此长时间游玩零漂移；暂停通过 `ctx.suspend()` 冻结时钟实现。

**人类可行性约束**（生成器与校验器双层保障）：同轨最小间隔（E 0.36s / H 0.20s / EX 0.135s，绝对下限 105ms）、同刻最大键数（E 1 / H·EX 2）、纵连键型长度上限（E 无 / H 2 / EX 4）、hold 最短时长与同轨不重叠、**hold 单侧约束**（hold 期间短键限对侧手区）。

**数据格式**：桌面版分析结果与谱面存于 `BeatChartData/library.json`、音频原件存于 `BeatChartData/audio/`；Android / 浏览器版存于 IndexedDB。

## 已知限制

- FLAC 支持取决于 Chromium 内置解码器，个别编码变体可能解码失败（会给出明确错误提示，换 MP3/WAV 即可）。
- 自动分析对极安静/纯氛围类音乐的 BPM 检测可能偏半倍频，可在重抽中消化（布局仍贴合 onset）。
